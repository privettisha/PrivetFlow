# Приватность PrivetFlow

PrivetFlow не отправляет данные разработчику и не использует аналитику. Расширение обрабатывает известные ответы Google Flow в памяти страницы и не сохраняет их содержимое.

В локальном хранилище браузера сохраняется только настройка `enabled`. На странице временно находятся технический статус, число распознанных и изменённых полей и число несовпадений формата. Эти значения доступны скриптам самой страницы, сбрасываются при её перезагрузке и не являются независимым доказательством доступа к сервису.

Кнопка «Скопировать отчёт» помещает в буфер обмена версию расширения, состояние переключателя, наличие вкладки Flow и диагностические счётчики. URL проектов, cookies, токены, адрес почты, изображения, видео и тексты запросов в отчёт не входят. Перед отправкой отчёта его можно просмотреть.

Google обрабатывает вашу работу в Flow по собственным правилам. Ссылки на GitHub и Telegram открываются только при нажатии и подчиняются правилам соответствующих сайтов. Расширение не проверяет обновления в фоне.

Для удаления локальных настроек удалите расширение. Чтобы удалить временные изменения страницы, перезагрузите вкладки Flow после удаления.
